# speechkit
A simple app to faciliate searching the UNGDC speech database.

Week 2 explorations of data showed that each country present for any given session gives exactly one speech that year,
and the speeches appear in inconveniently nested folders. All indexing info for each speech is present in the
filename of that speech within the nested folder.

Decided not to add a cleaner, since the text seems to have been thoroughly cleaned already.
